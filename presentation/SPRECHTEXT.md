## Slide 2 — Problem & Lösung

Wer Python lernt hat oft drei Probleme.
Man weiß nicht wo man steht.
Fehler werden nicht erklärt.
Und die KI vergisst alles nach jedem Chat.

Mein Tutor löst das.
Skill-Tree zeigt den Fortschritt.
Code Review erklärt Fehler auf Deutsch.
Und der Tutor erinnert sich an die letzte Session.

---

## Slide 3 — Was ich zeige

Ich zeige euch gleich alle Features live.
Chat, Code Review, Skills, Übungen und Lernplan.

---

## Slide 4 — Architektur

Kurz zur Technik.
Frontend ist Next.js, Backend ist FastAPI.
Der Kern ist ein LangChain Agent — er wählt selbst das richtige Tool.
Code Review läuft in drei Schritten — jeder Schritt baut auf dem vorherigen auf.
Alles läuft lokal, kein externer Dienst nötig.

Was würde ich anders machen?

Und eine echte Datenbank statt FAISS.
