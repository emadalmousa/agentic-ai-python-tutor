Das Problem — und die Lösung

Python lernen ist oft frustrierend

Klassische Tools bieten weder Personalisierung noch Kontext. Dieser Tutor löst das mit KI.

Das Problem
🗺️
Kein Überblick über den eigenen Fortschritt
Lernende wissen nicht, wo sie stehen und was als nächstes kommt.
🤷
Generisches, nicht-personalisiertes Feedback
Compiler-Fehler auf Englisch, keine Erklärung warum der Code falsch ist.
🔄
Jede Lernsession beginnt bei Null
KI-Chats kennen keinen Lernverlauf — der Kontext muss jedes Mal neu erklärt werden.
Die Lösung
🎯
Skill-Tree mit 37 Skills & Lernplan
3 Level (Beginner → Advanced), Fortschritt-Score pro Skill, personalisierter Wochenlernplan.
🔍
3-stufige Code-Review Chain
Syntax 🔴 → PEP8-Stil 🟡 → Best Practices 🔵 — stufenweise, mit Zeilennummer, auf Deutsch.
🧠
KI erinnert sich — sitzungsübergreifend
ConversationSummaryMemory: der Tutor weiß beim nächsten Login, wo man aufgehört hat.
Features

Alles, was ein guter Tutor können muss

Sechs Kernfunktionen — alle durch LLM-gestützte Agenten angetrieben.

Chat-Tutor
ReAct-Agent mit Werkzeugauswahl
Erklärt Konzepte, debuggt Code und generiert Übungen — wählt selbst das passende Tool basierend auf der Frage.
Code-Review Chain
3 Ebenen · 3 LLM-Aufrufe
Syntax-Fehler → PEP8-Stil → Best Practices. Jede Ebene separat bewertet, mit Zeilennummer und Verbesserungsvorschlag.
Skill-Tree & Übungen
37 Skills · 3 Level · Hints
Fortschritt-Score pro Skill, bis zu 3 progressive Hints, LLM-gestützte Bewertung mit erklärtem Feedback.
RAG-System
PDF hochladen → Tutor nutzt es
FAISS-Vektorindex lokal. Der Tutor antwortet mit Bezug auf hochgeladene Unterlagen und zitiert Seiten.
Agent-Gedächtnis
ConversationSummaryMemory
KI fasst Gespräche zusammen und erinnert sich beim nächsten Login — kein manuelles Eintippen des Kontexts.
Lernplan-Generator
Personalisiert · gecacht · wöchentlich
Schwache Skills zuerst, max. 3 Skills/Woche, Zeitschätzung, 28-Tage-Cache pro Nutzer.

Schnellstart

In 3 Minuten zum laufenden Tutor

Zwei Wege: mit Docker (empfohlen) oder manuell.

Option A — Docker (empfohlen)

# 1. Repo klonen
git clone https://github.com/emadalmousa/agentic-ai-python-tutor.git
cd agentic-ai-python-tutor

# 2. API-Key setzen
cp backend/.env.example backend/.env
# OPENAI_API_KEY=sk-... in backend/.env eintragen

# 3. Starten
docker compose up --build

# Frontend: http://localhost:3000
# Backend:  http://localhost:8000/docs

Option B — Manuell

# Backend
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# OPENAI_API_KEY in .env eintragen
uvicorn main:app --reload

# Frontend (neues Terminal)
cd frontend
npm install
npm run dev

# Oder beides mit:
./start.sh

Ohne OpenAI-Key — mit Ollama (lokal)

# Ollama installieren: https://ollama.com
ollama pull llama3.2
# Kein API-Key nötig — automatisch erkannt
./start.sh
